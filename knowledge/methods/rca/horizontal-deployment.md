# Horizontal deployment (yokoten)

## Purpose and principle
A countermeasure proved on one line copied — and checked — on every other line
with the same machine or the same failure mode.

## Questions it answers
Where else does this fix apply, and has each line taken it?

## Inputs and minimum conditions
The proved fix; the lines with the same machine or process.

## Procedure and calculation
Lines offered, taken, proved.

## Assumptions, limits and misuse
Copying without checking it works there.

## Reading the result
"Splice guide proved on line 3; offered to lines 1, 4, 7 — taken on 1."

—

## In food and FMCG manufacturing
Same wrappers or weighers across several lines.

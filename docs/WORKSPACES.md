# Clear workspaces — 17 November 2026

Rowland asked whether connecting every tool, test, project and Luna had made the app too difficult to operate, and authorised corrective action. This supersedes the 16 November rule that hides the global Tools door and the earlier fullscreen assistant shell.

The records stay linked where those links carry evidence or ownership. The interface gives each job a clear home:

| Home | Job |
| --- | --- |
| Tools | Choose a tool or reopen any saved use; no project required. |
| Testing | Plan and run verification, with criteria, evidence and results; no project required. |
| Projects | Organise selected work through an improvement method. |
| Factory | Organise lines, machines and their work, with place reports. |
| Luna | Optional help; the normal app navigation remains available. |

Tools has Library and Saved work views. Saved work is searchable, keeps each use distinct and respects the active client. Opening it from Tools stays in that workspace even when the record belongs to a project or line. Following an explicit line/project link leaves the workspace. Opening a record from the existing line or project flow keeps that flow. A URL presentation marker carries the workspace; it changes no saved record, permission or calculation.

Testing reuses the existing line-program verification flow, with active-client filtering. It does not merge check-log observations with formal planned trials. Projects remain optional for those programs. The phone bar gives direct access to Factory, Tools and Projects, with quick problem capture and More; Testing and Luna remain in More. The desktop order is Factory · Tools · Testing · Projects · Luna. Today is no longer a normal destination: Factory owns attention work, with actions/problems/projects opened in place. The old daily briefing URL remains compatible for existing links.

PDF content and its record links remain unchanged. A tool's own report stays with its record; place/project reports combine their explicitly associated work. No links are deleted and no records are copied merely to change navigation.

Acceptance: from Luna reach Tools and Projects directly; from Tools reopen a project-linked saved use without being moved into project navigation; its line/project links still open explicitly; tool view/list changes retain Tools; new standalone work has no project; Testing opens and runs a line's verification with no project and does not mix clients; phone/tablet/desktop navigation remains usable. These are proved by the workspace-separation acceptance and existing tool/testing/client/report stories.

## Follow-up: fewer moves, explicit places

Rowland's live review found duplicate Factory setup doors, extra dialogs for line settings and machine ordering, and unclear locations in Needs you now. Factory uses its Set up tab; existing lines do not get a second Set up the lines button. Unassigned areas are optional information, not a mandatory setup task. Factory setup exposes name editing and floor order directly. Machines exposes position on each editable row; Rename and Remove share More. A line's Set up view renders the existing settings editor directly, with primary sections visible; it does not open a second setup sheet. Attention cards show saved site/area/line/machine context without ellipsis and label multi-line project scope honestly. Their existing record links remain one click. No ownership or formula changes.

Choosing a tool's name in Library or a tool world opens its working list directly; About is explicitly secondary. Attention labels reuse their parent's existing records, avoiding extra whole-database reads. Line Settings is named separately from Factory Set up.

## Structural review: Today is not a workspace

Rowland challenged Today remaining in the sidebar on 17 November. Inspection found a read-only aggregation of the same lines, projects and actions, plus Luna prompts, recent places and role-dependent summaries. It owns no distinct work records. Those summaries do not justify a sixth workspace for personal use. Today is removed from desktop navigation, phone More and Everything. Its old route/role views remain compatible; no data, calculations or reports are removed. Factory's Needs you is the operational starting point, Projects owns project work, and Luna is optional assistance after the four workspaces.

Everything also had Factory and Lines pointing to the same /room address. The duplicate Lines jump is removed; actual named-line results remain. Testing now has its own jump, matching its existing workspace. The normal destination list has one entry for each purpose.

## Actions — 17 November follow-through repair

Actions has a distinct job: coordinate owned, dated work and review outcomes. It is a direct workspace between Tools and Testing, while the duplicate Today dashboard stays out of navigation. Phone navigation is Factory · Tools · Problem · Actions · More. A line's Actions tab shows its actual tasks and the existing problem-follow-up/dependency tracker. Tasks use the existing pace_todos records with an explicit standalone flag outside projects; creating a task does not create a fault. Source links connect records without moving their ownership.

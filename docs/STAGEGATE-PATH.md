# The stage-gate path — one page

Rowland, 27 October: *"What is a consistent issue with us is the blueprint of the
app .. we need a clear path for stage gate until we have this we will never
achieve what we want."* Then: *"Agreed do it."*

**This page is the stage gate.** Where an older document disagrees with it
(BLUEPRINT §3–4 on a project's pages, STAGEGATE, STAGEGATE-UX,
STAGEGATE-RESEARCH, STAGEGATE-REBUILD, SIMPLE, FLOW, PANELS), this page wins.
They are history from here (§5). Nothing is built for a stage-gate project that
is not on this page. A change to the path changes this page first, in the same
commit.

A stage-gate project is **new equipment taken to handover**: machines arrive,
each goes through four gates — **Install · Set up · Commission · Hand over** —
and the project is done when every machine is handed over. The unit on the
floor is the machine; the unit the business asks about is the project.
Rowland, 27 October: *"If I go to projects, I should be able to see my project
status ... If I go to machine, I want to be able to see everything associated
to my machine."*

---

## 1. The path — eight steps, start to handover

Each step: what the person does · where (the taps) · what is kept (the record) ·
where it shows afterwards.

| # | What you do | Where | What is kept | Where it shows |
|---|---|---|---|---|
| 1 | **Start the project** — its name, its line(s) from the Factory, the handover date agreed | Projects › **New project** › Stage gate | the project | Factory's board, Projects, the line's page |
| 2 | **Bring the machines in** — the line's own machines first, or a new one; who made it, due on site | Project › **Machines** › Add a machine | the machine (one record, on its line) | Machines tab, the machine's page, Factory › Machines, the line's Machines |
| 3 | **Plan each machine's gates** — each gate's usual list in one tap, a day on each step, who | Now › **Install / Set up / Commission / Hand over** | the steps and tests | Timeline, Now's next two weeks, the machine's four gates |
| 4 | **Run the day** — what is due today, what is late; tick a step done; a test passed or didn't pass | **Now** (today and late first) → the step or test opens in the drawer | the outcome, the day, who | Now's band and tiles, the machine's status, Journey |
| 5 | **When something goes wrong** — *Hit a problem* → the problem → *Make it a fix* (who, by when) → fixed → re-test | from the step or test, in the drawer | the problem and its fix | **Problems**, Now's *Blocking handover*, the machine's *What is open on it* |
| 6 | **Prove the programs** — each program tested at speed, passed or not, with what was seen | Now › **Programs** › *Test it* | the program and each of its tests | the machine's programs, Factory › Programs, the Programs report |
| 7 | **Hand over** — each machine's hand-over list done and signed; it reads *Handed over*; the project is done when all are | Now › **Hand over** | the hand-over items, who signed, what was still open | Now, the machine, Factory, the Handover report |
| 8 | **Tell people** — the right paper for the right reader | **Report ▾** on any page, or **Reports** | — (made from the records, never typed) | see §3 |

That is the whole path. A screen, button or list that does not serve one of
these eight steps is not part of the stage gate.

## 2. The places — and the one question each answers

A stage-gate project has **eight tabs**: **Now · Programs · Timeline · Gates · Machines · Problems · Reports · More** (28 October emergency UI — Programs and the Gantt are one tap each; the four gates share **Gates** with a switcher on gate pages only).

| Place | The question it answers | What is on it |
|---|---|---|
| **Now** (the front page) | *Where is the project, and what needs me?* | Are we on target · what blocks handover · the machines, a row each · today and the next two weeks · what you owe · doors to **Programs**, **Timeline**, **Commission**, **Machines** |
| **Programs** | *What runs on each machine, and did it pass?* | every program machine by machine · Test it and criteria on each row · add a program under each machine |
| **Timeline** | *When does everything happen?* | the Gantt — dates across the top, every machine's bars |
| **Gates** | *Install · Set up · Commission · Hand over* | the gate the project is in first; **Install · Set up · Commission · Hand over** across the top on gate pages |
| **Machines** | *Which machines, and where is each up to?* | a row a machine: status, where it is up to, programs, what it owes, what is next |
| **A machine** (from any machine name) | *Everything about this machine* | its status · *Going through <project> — up to <gate>* and its four gates · what is open on it · its tests · its programs · the machine itself (label, details) |
| **Problems** | *What is wrong, and who is fixing it?* | every problem and fix on the project, by priority, each with who and by when |
| **Reports** | *What do I send?* | every paper (§3) |
| **More** | the rest, rarely | Materials · Notes · Tools · Details |

Outside the project the same machines and programs are seen from the factory:
**Factory › Machines** (every machine, line by line) and **Factory › Programs**.

## 3. The papers — one per reader

| Paper | For | From |
|---|---|---|
| **Status report — 1 page** | the client, every week: are we on target, why, what we are doing | Now › Report ▾ |
| **Client report** | the full story: gates, machines, problems, programs | Now › Report ▾ |
| **Commissioning report** + **cards** | the meeting, the OEM: machine by machine, tests and programs | Commission, Machines, a machine › Report ▾ |
| **Machines report** | every machine, then a page each | Machines › Report ▾ |
| **Machine report** | one machine | a machine › Report ▾ |
| **Programs report** | the OEM and team: every program and test | Programs › Report ▾ |
| **Handover report** | whoever takes the line over | Hand over › Report ▾ |
| **Journey report** | what we did day by day, what is next | Reports |
| **Test cards** | the floor: what each test had to show | Commission › Report ▾ |

## 4. Every stage-gate screen today — keep, fold or remove

Measured 27 October: 21 project addresses, 62 in the app, 13 of them only
there to forward old links. **Nothing is removed until its replacement is live
and proved; every old address keeps opening where its job now lives.**

| Screen today | Decision | Why |
|---|---|---|
| Now (front page) | **keep** | step 4, the project's status |
| Machines | **keep** | step 2 |
| A machine | **keep** | the machine's whole story |
| Install · Set up · Hand over (one screen) | **keep**, as Now's views | steps 3, 7 |
| Commission | **keep**, as Now's view | steps 3–5 |
| Timeline (the plan) | **keep**, as Now's view | step 3, seen as days |
| Programs | **keep**, as Now's view | step 6 |
| Problems | **keep** | step 5 |
| Reports (client report and its papers) | **keep** | step 8 |
| Materials · Notes · Tools · Details | **keep**, under More | rarely used, nothing else does their job |
| **The day** | **fold into Journey** — *Today* is a day of the journey; its paper, *Today's update*, stays under Reports — **done 27 October** (Rowland: "fold it"): Journey's first range is *Today*; one day picked draws everything The day drew, then its commentary; `#/project/:id/day` opens it there; Now's *Today — …*, Reports' *Today*, Commission's *Read today* and Notes open it | Now already shows today; three places said today |
| **Journey** · **Actions** | **keep the pages; take them off the rail** — reached from Now (*Any dates ›*, *All actions ›*) and Reports | Now shows both in short; the rail listed them as places of their own |
| Rail: the second **Now** line (the old `/now` page) | **remove the line**; `/now` keeps forwarding to the front page | the same page twice |
| Rail: **The gates** line | **remove the line** | the gates are Now's views, one tap from the front page |
| Rail: a line per machine under Machines | **remove the lines** | Machines lists them; a rail of machine names grows with the project |
| A test's own page (`/test/:id`) | **keep only as an address** opening the test in the drawer | the drawer is the one home of a record (since 10 October) |

After this the rail of a stage-gate project is: **Now · Machines · Problems ·
Reports · More** — the same five as its tabs and its phone bar.
